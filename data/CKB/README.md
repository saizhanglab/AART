# CKB Paired Proteomics Data

The two proteomics tables are downloaded from:
https://doi.org/10.6084/m9.figshare.27931350

The ID mapping table (Supplementary Data 1) is from:
https://www.nature.com/articles/s41467-025-56935-2

## Expected files

| File | Description |
|------|-------------|
| `olink_overlap.csv` | Olink protein measurements (samples x proteins), `csid` as sample ID |
| `somascan_overlap.csv` | SomaScan aptamer measurements (samples x aptamers), `csid` as sample ID |
| `41467_2025_56935_MOESM4_ESM.xlsx` | Supplementary Data 1 — UniProt-based mapping between Olink and SomaScan |
